# Aquamarine — דף נחיתה לאמנית

דף נחיתה פשוט (Next.js) עם:

- **Above the fold** — הסיפור (ציטוט בכתב מוטה) מצד שמאל, תמונת פורטרט מצד ימין
- **קרוסלה** של יצירות נבחרות
- **סקשן** — ציטוט מימין, יצירה משמאל
- **סקשן** — ציטוט משמאל, יצירה מימין
- **צור קשר** — טלפון והזמנות מראש

## עריכת התוכן

כל הטקסטים, השם, מספר הטלפון והנתיבים לתמונות נמצאים בראש הקובץ
[`app/page.tsx`](app/page.tsx) בתוך הקבועים `ARTIST`, `HERO_STORY`,
`GALLERY`, `FEATURE_1`, `FEATURE_2`.

### החלפת תמונות

התמונות הזמניות הן קבצי SVG בתיקיית [`public/`](public/):
`portrait.svg`, `art-1..5.svg`, `feature-1.svg`, `feature-2.svg`.

מעלים את התמונות האמיתיות ל-`public/` ומעדכנים את הנתיבים ב-`app/page.tsx`.
(מומלץ להשתמש ב-JPG/PNG/WEBP — הם עוברים אופטימיזציה אוטומטית.)

## הרצה מקומית

```bash
npm install
npm run dev
```

הדף ירוץ ב-<http://localhost:3000>.

## פריסה ל-Vercel

מחברים את הריפו ל-Vercel — הוא מזהה Next.js אוטומטית ובונה ללא הגדרות נוספות.
